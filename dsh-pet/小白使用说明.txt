# 鲸鱼姐妹桌宠 · 小白安装指南

## 一、这是什么
两只会看屏幕、会拌嘴、能聊天的 Q 版鲸鱼女仆,住在你的桌面上。
会跳舞、会睡觉、能拖拽甩抛、互相碰撞——工作日白天每 2 分钟看一眼你的屏幕聊两句。

## 二、安装(二选一)
**方式 A · 安装包(推荐)**:双击 `dsh-pet-box-setup.exe` → 一路「下一步」→ 完成。
**方式 B · 绿色版**:解压 zip,双击里面的 `dsh-pet.exe`。

## 三、第一次启动(必须做,1 分钟)
第一次打开会自动弹出一个「AI 设置」页面。照着做:

1. 手机号注册 https://platform.deepseek.com (新账号有免费赠送额度)
2. 左侧菜单「API Keys」→「创建 API Key」→ 复制(只显示一次,立刻存!)
3. 粘贴到设置页的 API Key 框,模型选 deepseek-flash,点保存

不配 key 也能养(纯挂件模式),但她们不会说话。
**费用说明**:说话功能走你自己的 DeepSeek 账号,正常玩一天几毛到几块钱;不想要自动聊天,托盘右键可以关。

## 四、怎么玩
- **左键点她**:Q 弹回应 | **拖拽甩出去**:会飞会弹
- **右键她**:菜单(动画点播/睡觉/更多→看看屏幕/姐妹小剧场)
- **任务栏右下角托盘(鲸鱼图标)右键**:「聊天窗口」——手机样式的聊天窗,能打字聊、点喇叭听她念
- **两只撞在一起**:会互相弹开(真·物理碰撞)

## 五、常见问题
- **宠物不见了**:任务栏右下角隐藏区找鲸鱼图标,右键切换显示
- **她们不说话了**:多半是 key 没配好或 DeepSeek 余额不足,右键→打开 AI 设置 检查
- **嫌每 2 分钟太吵**:这是自动同屏会的频率,找给你包的人改(配置在安装目录 resources\box 里)
- **卸载**:方式 A 用「设置→应用」卸载;方式 B 删掉整个文件夹即可;配置残留在 `C:\Users\你的用户名\.dsh\dsh-pet\`,删了就是彻底干净
